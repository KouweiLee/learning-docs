# virtio设备的使用

## 命令行工具的设计

### el0

#### start zone

hvisor zone start -kernel Image.bin  0xxxx -dtb Image.dtb 0x0000 -id 1

```
bootm 0x40400000 - 0x40000000
insmod main.ko
sudo nohup ./hvisor virtio &
./hvisor zone start --kernel Image,addr=0x70000000 --dtb linux2.dtb,addr=0x91000000 --id 1
```

#### shutdown zone

```
./hvisor zone shutdown -id 1
```

#### virtio start

```
./hvisor virtio start \
	--device blk,addr=0x3000000,len=0x200,irq=55,zone_id=1,img=file.img \
    --device net,addr=0x3000000,len=0x200,irq=55,zone_id=1,tap=tap0
    
insmod main.ko
nohup ./hvisor virtio start \
	--device blk,addr=0xa003c00,len=0x200,irq=78,zone_id=1,img=rootfs2.ext4 \
	--device net,addr=0xa003600,len=0x200,irq=75,zone_id=1,tap=tap0 &
```

先getopt_long，获取到device后面的参数，然后用strtok分割`,`，看是addr还是啥，然后用`=`分割，获取值。

要启动virtio，必须是一次执行，否则是不同进程

开启virtio 主线程。之后可以指定blk有多少线程，net有多少线程

### 加载文件到内存的流程

1. 可参照jailhouse中read_file函数，将文件读到内存的一个其他地址
2. 将这些信息通过ioctl传递给内核（可参考cell_shutdown_load）
3. 内核可以通过类似与jailhouse_ioremap的函数，将image的内容拷贝到指定的物理地址。可以参考load_image。

通过copy_from_user，可以将用户态image所在的虚拟地址，指定大小的内容拷贝到内核态的一个虚拟地址。

通过__get_vm_area和ioremap_page_range函数，分配一个内核态的虚拟地址区域，并将物理区域映射到这个虚拟地址区域中。

### root linux的修改

在lib/ioremap.c文件中，加一行`EXPORT_SYMBOL_GPL(ioremap_page_range);`，以便ioremap_page_range在内核模块中可以正常使用。

## 制作磁盘镜像

```
apt-get update
apt-get install git sudo vim bash-completion
kmod net-tools iputils-ping resolvconf ntpdate
// 设置当前系统时间，以免时间不对应导致网络无法连接
ntpdate cn.ntp.org.cn 
参考https://www.cnblogs.com/liyong2019/p/16986581.html，设置dns服务器。这个命令应该可以：echo "nameserver 8.8.8.8" > /etc/resolv.conf
```
