# 设备树学习

## interrupts

interrupts属性后面，会有不同的参数，有时是两个，有时是三个：

两个的时候一般是这样出现：

```cpp
interrupt-parent = <&gpio2>;
interrupts = <29 0>;
```

一般这样表明：中断控制器是GPIO2，然后使用它的29号中断。(这里的29号，就是指29号引脚)，0是指触发的方式(上升沿、下降沿等)。

**知识点：中断发生设备与中断控制器的中断号对应关系：**

例如有这么个结构：

产生中断的设备A、B-->中断子控制器C-->GIC-->CPU

设备A和B的节点中，interrupts属性就包含2个参数，第一个参数表示连接到C的中断引脚号，可以理解成从C角度看到的A和B的中断号，但这个中断号不是CPU看到的。

C的设备树节点里有一个中断号，表示连接到GIC的中断号。A和B发给C的中断，C都会以一个统一的中断号发送给GIC（如果C中存在中断map的关系，则例外），这个统一的中断号就是C设备树节点中的中断号。

因此，CPU最终收到的A或B的中断，实际上是C的中断号。CPU这时会查询C对应的寄存器空间，判断是A还是B发出的中断。

三个的时候一般是这样出现：

```cpp
interrupts = <0 37 1>;
```

第一个参数表示是IPI、PPI、SPI、SGI其中的一个。对于NXP，0表示SPI。

第二个参数表示：是第一个参数里面的第几个

第三个参数表示：中断触发的类型。(上升沿、下降沿等)

```c
#define IRQ_TYPE_NONE        0
#define IRQ_TYPE_EDGE_RISING    1
#define IRQ_TYPE_EDGE_FALLING    2
#define IRQ_TYPE_EDGE_BOTH    (IRQ_TYPE_EDGE_FALLING | IRQ_TYPE_EDGE_RISING)
#define IRQ_TYPE_LEVEL_HIGH    4
#define IRQ_TYPE_LEVEL_LOW    8
```
