# 跑马灯

## 环境配置

下载vivado 2022.2：[下载 (xilinx.com)](https://china.xilinx.com/support/download/index.html/content/xilinx/zh/downloadNav/vivado-design-tools/archive.html)。直接从下载器下载vivado，下载时要选择企业版，个人版不支持ZCU102。之后可以把Versal ACAP取消勾选，否则占用100G磁盘空间。下载的过程比较慢，但安装比较快。

## 创建项目

启动vivado，选择Create Project，并填写项目名，注意路径什么的都得是英文的。

Project Type选择RTL Project，并勾选Do not specify sources at this time。

Default Part中选择Boards页，搜索zcu102，选中搜索出来的zcu102板子，之后点击next直到Finish。

## 创建verilog文件

点击Add Sources，选择Add or create design sources，创建一个顶层Verilog文件，设置模块的输入端口为：clk_p、clk_n，输出端口为leds[7:0]。

在该文件中加入以下内容：

```
module pl_top(
    input clk_p,
    input clk_n,
	input reset,
    output reg [7:0] leds
    );
    
    localparam PERIOD = 32'd125_000_000;
    wire clk;
    reg [31:0] counter;
    
	// initial block would be ignored when synthesis.

	// differential clock to single-ended clock
    IBUFDS
    #(
    .IOSTANDARD("DEFAULT")
    )
    IBUFDS_inst
    (
    .O(clk),
    .I(clk_p),
    .IB(clk_n)
    );
        
    always @(posedge clk) begin
		if(reset) begin
			counter <= 32'd0;
			leds <= 8'b00000001;
		end else begin
			case (counter)
				PERIOD-1: begin 
					counter <= 32'd0;
					leds <= {leds[6:0], leds[7]};
				end
				default: begin
					counter <= counter + 32'd1;
					leds <= leds;
				end
			endcase
		end
    end
    
endmodule
```

左边栏选择Run Implementation，结束后选择Open Implemented Design。在页面下方的Timing中看到时钟约束全部通过。

## 仿真教程

点击Add Sources，选择simulation source，创建一个顶层的simulation verilog文件。

在Sources窗口找到新建的仿真模块，双击打开，填入以下代码：

```
module tb_pl_top(

    );
    // TODO: 修改，加入reset
    //建立差分时钟
    reg clk_p = 1'b0;
    wire clk_n;
    assign clk_n = ~clk_p;
    
    //设置时钟周期为8ns
    always #4 clk_p = ~clk_p;
    
    //定义led输出
    wire [7:0] leds;
    
    //例化
    pl_top u
    (
    .clk_p(clk_p), 
    .clk_n(clk_n), 
    .leds(leds)
    );
    
endmodule
```

在Flow Navigator的SIMULATION中选择Run Simulation，在弹出菜单中选择Run Behavioral Simulation。

注意仿真时，可以修改主频和时钟周期，否则不太好看。
